# Task 03: Site-to-Site VPN Connection

[![Runbook](https://img.shields.io/badge/Type-Runbook-blue?style=flat-square)](./index.mdx)
[![Azure](https://img.shields.io/badge/Platform-Azure_Local-0078D4?style=flat-square&logo=microsoftazure)](https://learn.microsoft.com/en-us/azure/azure-local/)

> **DOCUMENT CATEGORY**: Runbook   
> **SCOPE**: S2S VPN Connection deployment   
> **PURPOSE**: Establish IPsec tunnel to on-premises network   
> **MASTER REFERENCE**: [Microsoft Learn - S2S VPN Connection](https://learn.microsoft.com/en-us/azure/vpn-gateway/tutorial-site-to-site-portal)

**Status**: Active

## Overview

This task creates the Local Network Gateway (representing the on-premises VPN device) and the Site-to-Site VPN Connection linking the Azure VPN Gateway (Task 02) to the on-premises network. The shared key is stored in Key Vault and retrieved at deployment time.

:::info Task Classification
**Execution Target**: Azure-Only (control-plane API operation) 
**Tab Profile**: 2 tabs — Azure Portal · Azure CLI / PowerShell
:::

:::info Terraform Reference
**Module:** `azurelocal-toolkit` 
**File:** `network.tf` 
**Mode:** Management
:::

### Components Created

| Resource | Name Pattern | Purpose |
|----------|-------------|---------|
| Local Network Gateway | `lgw-{workload}-{env}-{region}-{instance}` | On-prem VPN device representation |
| VPN Connection | `vnc-{workload}-{env}-{region}-{instance}` | IPsec/IKEv2 tunnel |

### Connection Configuration

| Setting | Value | Source |
|---------|-------|--------|
| Connection Type | IPsec | no key (the script or Azure decides it) |
| Protocol | IKEv2 | no key (the script or Azure decides it) |
| BGP Enabled | Per config | no key (the script or Azure decides it) |
| Routing Weight | Per config | no key (the script or Azure decides it) |
| Shared Key | Key Vault reference | `landing_zone.connectivity.vpn_gateway.site_to_site[].shared_key` |

## Prerequisites

- [ ] [Task 02: VPN Gateway](./task-02-vpn-gateway) completed — VPN Gateway is provisioned
- [ ] On-premises VPN device IP confirmed (e.g., `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_public_ip`)
- [ ] On-premises address prefixes confirmed (e.g., `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_address_prefixes`)
- [ ] Shared key stored in Key Vault at the URI in `landing_zone.connectivity.vpn_gateway.site_to_site[].shared_key`
- [ ] BGP ASN for on-premises device confirmed (if BGP enabled)

## Values from infrastructure.yml

The script reads these keys from `infrastructure.yml` (schema 5). Each key, with its type, default and example, is in the [variables reference](https://github.com/AzureLocal/azurelocal-toolkit/blob/main/config/variables/docs/VARIABLES.md).

```text
azure.tenant_id, azure.location, tags
landing_zone.connectivity.vpn_gateway.name, .resource_group, .network     the gateway (its resource group, else the one of the network)
landing_zone.networks[].name, .subscription, .resource_group, .location   where the network, and so the gateway, is
landing_zone.subscriptions[].name, .id                                    the subscription that holds the network
landing_zone.connectivity.vpn_gateway.site_to_site[]: connection_name, local_gateway_name, peer_public_ip, peer_address_prefixes,
                                                      peer_bgp_address, peer_asn, shared_key
```

### Azure Portal

> **When to use**: Learning Azure Local, single deployment, prefer visual interface

#### Procedure

1. **Create Local Network Gateway**:
 - Search for **Local network gateways** → **+ Create**
 | Field | Value | Source |
 |-------|-------|--------|
 | Name | `lgw-{workload}-{env}-{region}-01` | `landing_zone.connectivity.vpn_gateway.site_to_site[].local_gateway_name` |
 | Resource Group | Same as VPN Gateway | `landing_zone.connectivity.vpn_gateway.resource_group` |
 | Region | Your region | `azure.location` |
 | Endpoint | IP address | — |
 | IP address | On-prem device IP | `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_public_ip` |
 | Address Space | On-prem prefixes | `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_address_prefixes` |

2. **Configure BGP on Local Gateway** (if enabled):
 | Field | Value | Source |
 |-------|-------|--------|
 | Configure BGP | Yes | no key (the script or Azure decides it) |
 | ASN | On-prem ASN | `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_asn` |
 | BGP peer address | On-prem BGP peer | `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_bgp_address` |

3. **Create VPN Connection**:
 - Navigate to VPN Gateway → **Connections** → **+ Add**
 | Field | Value | Source |
 |-------|-------|--------|
 | Name | `vnc-{workload}-{env}-{region}-01` | `landing_zone.connectivity.vpn_gateway.site_to_site[].connection_name` |
 | Connection type | Site-to-site (IPsec) | no key (the script or Azure decides it) |
 | Local network gateway | Select from Step 1 | `landing_zone.connectivity.vpn_gateway.site_to_site[].local_gateway_name` |
 | Shared key (PSK) | From Key Vault | `landing_zone.connectivity.vpn_gateway.site_to_site[].shared_key` |
 | IKE Protocol | IKEv2 | no key (the script or Azure decides it) |
 | Enable BGP | Per config | no key (the script or Azure decides it) |

4. **Configure On-Premises Device**: Configure the on-premises VPN device (e.g., no key (the script or Azure decides it)) with matching settings.

5. **Review + create**: Verify → Click **OK**

#### Validation

- [ ] Local Network Gateway provisioning state: **Succeeded**
- [ ] VPN Connection status: **Connected**
- [ ] BGP peers established (if BGP enabled)

## Troubleshooting

| Issue | Root Cause | Remediation |
|-------|-----------|-------------|
| Connection stuck at **Connecting** | Shared key mismatch | Verify PSK matches on both sides |
| Connection stuck at **Connecting** | On-prem device not configured | Configure on-prem VPN device with matching settings |
| BGP peers not established | ASN mismatch or APIPA mismatch | Verify ASN and APIPA addresses match both sides |
| Cannot resolve Key Vault secret | Missing RBAC or network access | Add `Key Vault Secrets User` role; check firewall |
| Local gateway IP incorrect | Wrong public IP for on-prem device | Update `landing_zone.connectivity.vpn_gateway.site_to_site[].peer_public_ip` |
| IKE Phase 1 failure | Encryption/integrity mismatch | Align IKE parameters between Azure and on-prem device |
