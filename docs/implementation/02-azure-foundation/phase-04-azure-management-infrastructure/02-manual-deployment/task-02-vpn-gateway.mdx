## Overview

This task deploys an Azure VPN Gateway into the GatewaySubnet created in Task 01. The gateway provides site-to-site IPsec/IKEv2 connectivity between Azure and on-premises infrastructure with BGP routing support.

:::warning Deployment Time
The VPN Gateway takes **30–45 minutes** to deploy. Do not interrupt the deployment. Plan accordingly.
:::

:::info Task Classification
**Execution Target**: Azure-Only (control-plane API operation) 
**Tab Profile**: 2 tabs — Azure Portal · Azure CLI / PowerShell
:::

:::info Terraform Reference
**Module:** `azurelocal-toolkit` 
**File:** `network.tf` 
**Mode:** Management
:::

### Components Created

| Resource | Name Pattern | Purpose |
|----------|-------------|---------|
| Public IP | `pip-azrlvpng-{env}-{region}-01` | VPN Gateway public IP |
| VPN Gateway | `vpng-azrl-{env}-{region}-01` | Site-to-site VPN termination |

### Gateway Configuration

| Setting | Value | Source |
|---------|-------|--------|
| SKU | `VpnGw2AZ` | `landing_zone.connectivity.vpn_gateway.sku` |
| Generation | Generation2 | no key (the script or Azure decides it) |
| Type | Route-based | Standard for Azure Local |
| Active-Active | Per config | no key (the script or Azure decides it) |
| BGP Enabled | Per config | no key (the script or Azure decides it) |
| BGP ASN | Per config | `landing_zone.connectivity.vpn_gateway.bgp_asn` |

## Prerequisites

- [ ] [Task 01: Virtual Network](./task-01-virtual-network) completed — GatewaySubnet exists
- [ ] Public IP address not already in use
- [ ] BGP ASN confirmed by on-premises network team (must not conflict)

## Values from infrastructure.yml

The script reads these keys from `infrastructure.yml` (schema 5). Each key, with its type, default and example, is in the [variables reference](https://github.com/AzureLocal/azurelocal-toolkit/blob/main/config/variables/docs/VARIABLES.md).

```text
azure.tenant_id                                       the tenant the sign-in must belong to
azure.location                                        the region, when the network entry has none
tags                                                  tags for the resources created (optional)
landing_zone.connectivity.vpn_gateway.name            the gateway name
landing_zone.connectivity.vpn_gateway.resource_group  the resource group of the gateway (else the one of the network)
landing_zone.connectivity.vpn_gateway.network         the virtual network (an entry of landing_zone.networks)
landing_zone.connectivity.vpn_gateway.sku             the SKU (VpnGw1AZ to VpnGw5AZ)
landing_zone.connectivity.vpn_gateway.bgp_asn         the BGP ASN of the gateway
landing_zone.networks[].name, .subscription, .resource_group, .location   where the network is
landing_zone.subscriptions[].name, .id                the subscription that holds the network and so the gateway
```

### Azure Portal

> **When to use**: Learning Azure Local, single deployment, prefer visual interface

#### Procedure

1. **Create Public IP**:
 - Search for **Public IP addresses** → **+ Create**
 | Field | Value | Source |
 |-------|-------|--------|
 | Name | `pip-azrlvpng-{env}-{region}-01` | no key (the script or Azure decides it) |
 | SKU | Standard | Required for AZ gateway |
 | Assignment | Static | Required for VPN Gateway |
 | Availability Zone | Zone-redundant | Best practice |

2. **Create VPN Gateway**:
 - Search for **Virtual network gateways** → **+ Create**
 | Field | Value | Source |
 |-------|-------|--------|
 | Name | `vpng-azrl-{env}-{region}-01` | `landing_zone.connectivity.vpn_gateway.name` |
 | Region | Your region | `landing_zone.connectivity.vpn_gateway.resource_group` |
 | Gateway type | VPN | — |
 | SKU | VpnGw2AZ | `landing_zone.connectivity.vpn_gateway.sku` |
 | Generation | Generation2 | no key (the script or Azure decides it) |
 | Virtual network | VNet from Task 01 | `landing_zone.networks[].name` |
 | Public IP | Public IP created above | no key (the script or Azure decides it) |
 | Enable active-active | Per config | no key (the script or Azure decides it) |

3. **Configure BGP** (if enabled):
 | Field | Value | Source |
 |-------|-------|--------|
 | Configure BGP | Yes | no key (the script or Azure decides it) |
 | ASN | Per config | `landing_zone.connectivity.vpn_gateway.bgp_asn` |
 | Custom Azure APIPA BGP address | Per config | no key (the script or Azure decides it) |

4. **Review + create**: Verify → Click **Create** → Wait 30–45 minutes

#### Validation

- [ ] Public IP assigned and visible
- [ ] BGP settings correct (if enabled)
- [ ] Gateway associated with correct GatewaySubnet

## Troubleshooting

| Issue | Root Cause | Remediation |
|-------|-----------|-------------|
| Deployment fails after 45 min | Transient Azure platform issue | Retry; check Azure Status page |
| GatewaySubnet not found | Task 01 not completed | Complete Task 01 first |
| BGP ASN conflict | ASN already in use by another gateway | Choose unique ASN in Planning & Discovery |
| Public IP SKU mismatch | Basic SKU used with AZ gateway | Use Standard SKU with zone-redundant allocation |
| Active-active requires 2 PIPs | Single PIP with active-active | Create second PIP or disable active-active |
