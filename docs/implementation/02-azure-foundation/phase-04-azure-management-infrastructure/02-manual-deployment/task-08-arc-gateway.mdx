## Overview

This task deploys an Azure Arc Gateway resource. The Arc Gateway provides a centralized network endpoint that Arc-enabled servers use to communicate with Azure services, reducing the number of required firewall rules for on-premises infrastructure.

:::info Task Classification
**Execution Target**: Azure-Only (control-plane API operation)
**Tab Profile**: 2 tabs — Azure Portal · Azure CLI / PowerShell
:::

:::danger Decide before you deploy the cluster
The Arc gateway can only be enabled during deployment of a new Azure Local instance (software version 2506 or later). It cannot be enabled after deployment. Decide whether to use it, and create the gateway resource in the subscription that will host the instance, before you register the machines.

If your environment inspects or terminates TLS, Arc gateway is not recommended and does not support TLS-terminating proxies. Skip TLS inspection for the gateway endpoint (`<your URL prefix>.gw.arc.azure.com`).

Source: [Overview of Azure Arc gateway for Azure Local](https://learn.microsoft.com/en-us/azure/azure-local/deploy/deployment-azure-arc-gateway-overview?view=azloc-2609#supported-and-unsupported-scenarios) and [Azure Arc gateway limitations](https://learn.microsoft.com/en-us/azure/azure-arc/servers/arc-gateway#current-limitations).
:::

:::warning Azure API Resource
The Arc Gateway uses the `Microsoft.HybridCompute/gateways` resource type. As of this writing, it requires the AzAPI provider in Terraform (not yet in azurerm).
:::

:::info Terraform Reference
**Module:** `azurelocal-toolkit`

### Azure Portal

> **When to use**: Learning Azure Local, single deployment, prefer visual interface

#### Procedure

1. **Register Resource Provider** (if not already):

- Subscription → **Resource providers** → Search `Microsoft.HybridCompute` → **Register**

2. **Create Arc Gateway**:

- Search for **Arc Gateways** (or **Azure Arc** → **Arc Gateways**)
- Click **+ Create**
  | Field | Value | Source |
  |-------|-------|--------|
  | Name | Per config | `networking.outbound.arc_gateway.name` |
  | Subscription | Target subscription | `landing_zone.subscriptions[].id` |
  | Resource Group | Cluster RG | `networking.outbound.arc_gateway.resource_group` |
  | Region | Your region | `azure.location` |
  | Gateway Type | Public | Only option |

3. **Review + create**: Verify → Click **Create** → Record the **Gateway Endpoint** URL

4. **Note the Gateway ID**: Copy the full resource ID — it will be needed during Azure Local cluster deployment:

```
/subscriptions/{sub}/resourceGroups/{rg}/providers/Microsoft.HybridCompute/gateways/{name}
```

## Troubleshooting

| Issue                            | Root Cause                            | Remediation                                    |
| -------------------------------- | ------------------------------------- | ---------------------------------------------- |
| Resource provider not registered | `Microsoft.HybridCompute` not enabled | Register via Subscription → Resource providers |
| 403 Forbidden on REST API        | Insufficient permissions              | Need Contributor on resource group             |
| Gateway endpoint not available   | Deployment still propagating          | Wait 5 minutes and query again                 |
| Arc agent cannot reach gateway   | Firewall blocking gateway endpoint    | Allow `*.gw.arc.azure.net` on port 443         |
