**Status**: Active

## Overview

This task configures Point-to-Site (P2S) VPN on the existing VPN Gateway (Task 02) to allow individual administrators to connect remotely to the Azure management network. P2S VPN is **optional** — it provides an alternative to Azure Bastion for remote management scenarios.

:::info Task Classification
**Execution Target**: Azure-Only (control-plane API operation) 
**Tab Profile**: 2 tabs — Azure Portal · Azure CLI / PowerShell
:::

:::warning Optional Task
This task is optional. It is only required when remote administrative VPN access is needed in addition to or instead of Azure Bastion (Task 05).
:::

:::info Terraform Reference
**Module:** `azurelocal-toolkit` 
**File:** `network.tf` 
**Mode:** Management
:::

### Components Configured

| Resource | Name Pattern | Purpose |
|----------|-------------|---------|
| P2S VPN Configuration | On existing VPN Gateway | Remote admin VPN access |
| VPN Client Address Pool | Per config | IP pool for VPN clients |

### P2S Configuration

| Setting | Value | Source |
|---------|-------|--------|
| Authentication | Certificate or Entra ID | `landing_zone.connectivity.vpn_gateway.point_to_site.authentication` |
| Tunnel Type | OpenVPN | `landing_zone.connectivity.vpn_gateway.point_to_site.protocols` |
| Client Address Pool | Per config | `landing_zone.connectivity.vpn_gateway.point_to_site.address_pool` |
| Root Certificate | Key Vault reference | `landing_zone.connectivity.vpn_gateway.point_to_site.root_certificate` |

## Prerequisites

- [ ] [Task 02: VPN Gateway](./task-02-vpn-gateway) completed — VPN Gateway provisioned
- [ ] Root certificate generated and uploaded to Key Vault (if using certificate auth)
- [ ] Entra ID application registered (if using Entra ID authentication)
- [ ] Client address pool CIDR does not overlap with VNet or on-premises ranges

## Values from infrastructure.yml

The script reads these keys from `infrastructure.yml` (schema 5). Each key, with its type, default and example, is in the [variables reference](https://github.com/AzureLocal/azurelocal-toolkit/blob/main/config/variables/docs/VARIABLES.md).

```text
azure.tenant_id, azure.location
landing_zone.connectivity.vpn_gateway.name, .resource_group, .network            the gateway
landing_zone.networks[].name, .subscription, .resource_group                     where the network, and so the gateway, is
landing_zone.subscriptions[].name, .id                                           the subscription that holds the network
landing_zone.connectivity.vpn_gateway.point_to_site.address_pool, .authentication, .protocols, .root_certificate_name, .root_certificate
```

### Execution Options

### Azure Portal

> **When to use**: Learning Azure Local, single deployment, prefer visual interface

#### Procedure

1. **Navigate to VPN Gateway**:
 - Search for **Virtual network gateways** → Select the gateway from Task 02

2. **Configure Point-to-Site**:
 - Go to **Point-to-site configuration** → **Configure now**
 | Field | Value | Source |
 |-------|-------|--------|
 | Address pool | Client CIDR | `landing_zone.connectivity.vpn_gateway.point_to_site.address_pool` |
 | Tunnel type | OpenVPN (SSL) | `landing_zone.connectivity.vpn_gateway.point_to_site.protocols` |
 | Authentication type | Azure certificate or Entra ID | `landing_zone.connectivity.vpn_gateway.point_to_site.authentication` |

3. **Upload Root Certificate** (if certificate auth):
 | Field | Value | Source |
 |-------|-------|--------|
 | Name | Root cert name | `landing_zone.connectivity.vpn_gateway.point_to_site.root_certificate_name` |
 | Public certificate data | Base64 cert data | From Key Vault |

4. **Configure Entra ID** (if Entra ID auth):
 | Field | Value | Source |
 |-------|-------|--------|
 | Tenant | Entra tenant ID | `azure.tenant_id` |
 | Audience | Entra app ID | no key (the script or Azure decides it) |
 | Issuer | `https://sts.windows.net/{tenant-id}/` | Derived from tenant |

5. **Save** the configuration

6. **Download VPN Client**: Click **Download VPN client** → Distribute to authorized admins

- [ ] P2S configuration saved on VPN Gateway
- [ ] VPN client profile downloadable
- [ ] Test client connects successfully
- [ ] Client receives IP from configured pool

## Troubleshooting

| Issue | Root Cause | Remediation |
|-------|-----------|-------------|
| Client cannot connect | Root cert not trusted | Verify root cert uploaded correctly |
| No IP assigned to client | Address pool exhausted or misconfigured | Expand pool or verify CIDR |
| Address pool overlaps | CIDR conflicts with VNet or on-prem | Choose non-overlapping CIDR |
| Entra ID auth fails | App registration misconfigured | Verify tenant ID, audience, and API permissions |
| OpenVPN not available | Gateway SKU too low | Upgrade to VpnGw2AZ or higher |
