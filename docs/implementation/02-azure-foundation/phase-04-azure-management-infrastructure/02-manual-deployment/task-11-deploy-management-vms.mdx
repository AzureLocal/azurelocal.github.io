**Status**: Active

## Overview

This task deploys all five management VMs needed for the Azure Local environment. Each VM is deployed from Azure Marketplace images into the management subnet. OS-level configuration (AD DS, utilities, etc.) is handled in Tasks 12–16.

:::info Task Classification
**Execution Target**: Azure-Only (control-plane API operation) 
**Tab Profile**: 2 tabs — Azure Portal · Azure CLI / PowerShell
:::

:::warning Admin Credentials
VM admin passwords are stored in Key Vault. **Never** hardcode passwords. Retrieve the admin password from `keyvault://kv-{name}/azlocal-admin-password` at deploy time.
:::

:::info Terraform Reference
**Module:** `azurelocal-toolkit` 
**Files:** `nic.tf`, VM resources 
**Mode:** Management
:::

### VMs to Deploy

| VM Key | Name | Role | OS | Size | IP | Config Path |
|--------|------|------|----|------|----|-------------|
| dc01 | `vm-azrldc-{env}-{region}-01` | Primary Domain Controller | Windows Server 2025 | Standard_D2s_v4 | Per config | `landing_zone.virtual_machines[]` |
| dc02 | `vm-azrldc-{env}-{region}-02` | Secondary Domain Controller | Windows Server 2025 | Standard_D2s_v4 | Per config | `landing_zone.virtual_machines[]` |
| utility | `vm-util-{env}-{region}-01` | Utility/Management Server | Windows Server 2025 | Standard_D2as_v6 | Per config | `landing_zone.virtual_machines[]` |
| ndm | `vm-ndm-{env}-{region}-01` | NDM (SYSLOG/SNMP) | Ubuntu 24.04 LTS | Standard_D2s_v4 | Per config | `landing_zone.virtual_machines[]` |
| lighthouse | `vm-lh-{env}-{region}-01` | Lighthouse Central Mgmt | OpenGear Lighthouse | Standard_D2s_v4 | Per config | `landing_zone.virtual_machines[]` |

The script reads these keys from `infrastructure.yml` (schema 5). Each key, with its type, default and example, is in the [variables reference](https://github.com/AzureLocal/azurelocal-toolkit/blob/main/config/variables/docs/VARIABLES.md).

```text
azure.tenant_id, azure.location, tags
landing_zone.virtual_machines[]: name, hostname, role, deploy_target, subscription, resource_group, network, subnet, private_ip, size, os,
                                 admin_username, admin_password
landing_zone.networks[].name, .subscription, .resource_group, .location     where the network is
landing_zone.subscriptions[].name, .id                                      the subscription that holds the network
```

### Azure Portal

> **When to use**: Learning Azure Local, single deployment, prefer visual interface

#### Procedure (repeat for each VM)

1. **Create Virtual Machine**:
 - Search for **Virtual machines** → **+ Create** → **Azure virtual machine**

2. **Basics**:
 | Field | Value | Source |
 |-------|-------|--------|
 | Name | Per VM table above | `landing_zone.virtual_machines[]` |
 | Region | Your region | `landing_zone.virtual_machines[]` |
 | Image | Per VM table | `landing_zone.virtual_machines[]` |
 | Size | Per VM table | `landing_zone.virtual_machines[]` |
 | Username | `azureadmin` | Standard |
 | Password | From Key Vault | `keyvault://<vault>/azlocal-admin-password` |

3. **Disks**:
 | Field | Value | Source |
 |-------|-------|--------|
 | OS disk type | Premium SSD | `landing_zone.virtual_machines[]` |
 | OS disk size | Per config | `landing_zone.virtual_machines[]` |

4. **Networking**:
 | Field | Value | Source |
 |-------|-------|--------|
 | Virtual network | Management VNet | `landing_zone.networks[].name` |
 | Subnet | Management subnet | `landing_zone.virtual_machines[]` |
 | Public IP | None | No public IPs on mgmt VMs |
 | NIC name | Per config | `landing_zone.virtual_machines[]` |

5. **Advanced → IP Configuration**: Set static private IP:
 | Field | Value | Source |
 |-------|-------|--------|
 | Private IP | Static | `landing_zone.virtual_machines[]` |

6. **Review + create**: Verify → Click **Create**

7. **Repeat** for all 5 VMs

#### Validation

- [ ] All 5 VMs provisioning state: **Succeeded**
- [ ] Each VM has correct static private IP
- [ ] No public IPs assigned
- [ ] All VMs accessible via Bastion (Task 05)

## Troubleshooting

| Issue | Root Cause | Remediation |
|-------|-----------|-------------|
| VM size not available | Quota or region limitation | Request quota increase or change region |
| Marketplace terms not accepted | OpenGear Lighthouse requires acceptance | `Set-AzMarketplaceTerms -Publisher opengear -Product lighthouse -Name lighthouse -Accept` |
| Static IP conflict | IP already in use | Verify IP availability in subnet |
| Password too weak | Azure policy enforced | Use 12+ chars with upper, lower, number, special |
| NIC creation fails | Subnet NSG blocking | Check NSG rules on management subnet |
