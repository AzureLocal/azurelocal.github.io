## Overview

This step validates the backup and disaster recovery capabilities for the Azure Local cluster, including backup operations of the chosen backup solution, test restores, and DR failover validation.

## Prerequisites

- [ ] All previous validation steps completed (Steps 1-5)
- [ ] Backup solution configured (Stage 17)
- [ ] Azure Site Recovery configured (if applicable)
- [ ] Test VM available for restore testing
- [ ] Sufficient storage for restore operations

## Part 2: Backup Configuration Validation

### 2.1 Verify the backup agent or service on each node

Set `$AgentServiceName` to the service name used by the chosen backup solution. Check every cluster node and record the service status and start type.

```powershell
$serviceResults = foreach ($node in Get-ClusterNode -Cluster $ClusterName) {
    Invoke-Command -ComputerName $node.Name -ArgumentList $AgentServiceName -ScriptBlock {
        param($ServiceName)

        $service = Get-Service -Name $ServiceName -ErrorAction SilentlyContinue
        if ($null -eq $service) {
            [pscustomobject]@{
                Node      = $env:COMPUTERNAME
                Service   = $ServiceName
                Status    = 'Not found'
                StartType = 'Not available'
            }
        }
        else {
            [pscustomobject]@{
                Node      = $env:COMPUTERNAME
                Service   = $service.Name
                Status    = $service.Status
                StartType = $service.StartType
            }
        }
    }
}

$serviceResults | ForEach-Object {
    Add-Content $ReportFile ("Service check: Node={0}; Service={1}; Status={2}; StartType={3}" -f $_.Node, $_.Service, $_.Status, $_.StartType)
}
```

### 2.2 Verify protection coverage

List every VM across the cluster and compare it with the chosen backup solution's console. Fill in the remaining columns by hand.

$vmInventory = foreach ($node in Get-ClusterNode -Cluster $ClusterName) {

### 2.3 Check VSS Writers

Run the writer check on each node. Any writer not in a stable state with no error requires investigation.

```powershell
foreach ($node in Get-ClusterNode -Cluster $ClusterName) {
    $writerOutput = Invoke-Command -ComputerName $node.Name -ScriptBlock {
        (& vssadmin.exe list writers 2>&1 | Out-String)
    }

    Add-Content $ReportFile ("VSS writer output for node {0}:" -f $node.Name)
    Add-Content $ReportFile $writerOutput

    $writerBlocks = [regex]::Matches(
        $writerOutput,
        "(?ms)Writer name:\s*'(?<Name>[^']+)'.*?State:\s*\[(?<StateNumber>\d+)\]\s*(?<State>[^\r\n]+).*?Last error:\s*(?<LastError>[^\r\n]+)"
    )

    if ($writerBlocks.Count -eq 0) {
        Add-Content $ReportFile ("VSS writer check: Node={0}; Status=Review output; writer state could not be parsed" -f $node.Name)
    }
    else {
        foreach ($writer in $writerBlocks) {
            $state = $writer.Groups['State'].Value.Trim()
            $writerError = $writer.Groups['LastError'].Value.Trim()

            if ($state -notmatch '^Stable$' -or $writerError -notmatch '^No error$') {
                Add-Content $ReportFile ("VSS writer issue: Node={0}; Writer={1}; State={2}; Error={3}" -f $node.Name, $writer.Groups['Name'].Value, $state, $writerError)
            }
            else {
                Add-Content $ReportFile ("VSS writer OK: Node={0}; Writer={1}" -f $node.Name, $writer.Groups['Name'].Value)
            }
        }
    }
}
```

## Part 3: Backup Job Validation

### 3.1 Review recent backup jobs

Export job history for the last 7 days from the chosen backup solution to `$ReportPath\backup-jobs.csv`. The CSV must contain `Datasource`, `Status`, `Start`, and `End` columns. This check counts rows with a `Status` of `Success` as successful and flags a success rate below 95 percent.

```powershell
$csvPath = Join-Path $ReportPath 'backup-jobs.csv'

if (-not (Test-Path $csvPath)) {
    Add-Content $ReportFile ("Backup job review: CSV not found at {0}" -f $csvPath)
}
else {
    $jobs = @(Import-Csv $csvPath)
    $requiredColumns = 'Datasource', 'Status', 'Start', 'End'

    if ($jobs.Count -eq 0) {
        Add-Content $ReportFile 'Backup job review: No job rows found in the CSV.'
    }
    else {
        $missingColumns = $requiredColumns | Where-Object { $_ -notin $jobs[0].PSObject.Properties.Name }

        if ($missingColumns) {
            Add-Content $ReportFile ("Backup job review: Missing CSV columns: {0}" -f ($missingColumns -join ', '))
        }
        else {
            $successCount = @($jobs | Where-Object { $_.Status -eq 'Success' }).Count
            $successRate = [math]::Round(($successCount / $jobs.Count) * 100, 2)
            $result = if ($successRate -lt 95) { 'FLAG: below 95 percent' } else { 'Pass' }

            Add-Content $ReportFile ("Backup job review: Total={0}; Successful={1}; SuccessRate={2}%; Result={3}" -f $jobs.Count, $successCount, $successRate, $result)
        }
    }
}
```

## Part 4: Restore Validation

### 4.1 Test VM restore

Use the chosen backup solution to restore a test VM to an alternate location with a different name. Record the restore start and end times in the report file and calculate the RTO from those times.

### 4.2 Verify the restored VM

Set `$RestoredVMName` to the alternate name used for the restored VM. Check its state, start it if needed, and wait for the heartbeat integration service to report `OK`. After approval, clean up the test VM using the chosen solution or the appropriate operational process.

```powershell
$restoredVM = $null

foreach ($node in Get-ClusterNode -Cluster $ClusterName) {
    $restoredVM = Get-VM -ComputerName $node.Name -Name $RestoredVMName -ErrorAction SilentlyContinue |
        Select-Object -First 1

    if ($null -ne $restoredVM) {
        break
    }
}

if ($null -eq $restoredVM) {
    Add-Content $ReportFile ("Restore verification: VM={0}; Result=Not found" -f $RestoredVMName)
}
else {
    Add-Content $ReportFile ("Restore verification: VM={0}; InitialState={1}" -f $restoredVM.Name, $restoredVM.State)

    if ($restoredVM.State -ne 'Running') {
        Start-VM -VM $restoredVM
    }

    $deadline = (Get-Date).AddMinutes(10)
    $heartbeatStatus = 'Timed out'

    do {
        Start-Sleep -Seconds 10
        $heartbeat = Get-VMIntegrationService -VM $restoredVM -Name 'Heartbeat' -ErrorAction SilentlyContinue

        if ($heartbeat -and $heartbeat.PrimaryStatusDescription -eq 'OK') {
            $heartbeatStatus = 'OK'
            break
        }
    } while ((Get-Date) -lt $deadline)

    Add-Content $ReportFile ("Restore verification: VM={0}; FinalState={1}; Heartbeat={2}" -f $restoredVM.Name, (Get-VM -ComputerName $restoredVM.ComputerName -Name $restoredVM.Name).State, $heartbeatStatus)
}
```

### 4.3 File-level restore test

Restore one file to a temporary path using the chosen backup solution. Set `$SourceFile` and `$RestoredFile` to the source and restored file paths, then compare their hashes.

```powershell
$SourceFile = 'SET_SOURCE_FILE_PATH'
$RestoredFile = 'SET_RESTORED_FILE_PATH'

if (-not (Test-Path $SourceFile)) {
    Add-Content $ReportFile ("File restore check: Source file not found: {0}" -f $SourceFile)
}
elseif (-not (Test-Path $RestoredFile)) {
    Add-Content $ReportFile ("File restore check: Restored file not found: {0}" -f $RestoredFile)
}
else {
    $sourceHash = Get-FileHash -Path $SourceFile
    $restoredHash = Get-FileHash -Path $RestoredFile
    $result = if ($sourceHash.Hash -eq $restoredHash.Hash) { 'Pass' } else { 'Fail' }

    Add-Content $ReportFile ("File restore check: Source={0}; Restored={1}; Match={2}; Result={3}" -f $SourceFile, $RestoredFile, ($sourceHash.Hash -eq $restoredHash.Hash), $result)
}
```

## Part 5: Recovery Point Verification

### 5.1 Check the recovery point inventory

For three sample VMs, record the number and age of recovery points shown in the chosen backup solution's console. Enter the newest recovery point time for each VM in `$RecoveryPointTimes`. The check compares each entered time with `$RpoHours`.

```powershell
$RpoHours = 24   # set to the agreed RPO in hours
$RecoveryPointTimes = @{
    # 'VM name' = [datetime]'YYYY-MM-DD HH:MM:SS'
}

if ($RecoveryPointTimes.Count -eq 0) {
    Add-Content $ReportFile 'Recovery point check: No recovery point times entered.'
}
else {
    foreach ($vmName in $RecoveryPointTimes.Keys) {
        $recoveryPointTime = [datetime]$RecoveryPointTimes[$vmName]
        $ageHours = ((Get-Date) - $recoveryPointTime).TotalHours
        $result = if ($ageHours -le $RpoHours) { 'Within RPO' } else { 'Outside RPO' }

        Add-Content $ReportFile ("Recovery point check: VM={0}; NewestRecoveryPoint={1}; AgeHours={2}; RpoHours={3}; Result={4}" -f $vmName, $recoveryPointTime, ([math]::Round($ageHours, 2)), $RpoHours, $result)
    }
}
```

## Part 7: Azure Site Recovery Validation (If Configured)

### 7.1 Check ASR Replication Status

```powershell
"`n" + "="*80 | Add-Content $ReportFile
"AZURE SITE RECOVERY (IF CONFIGURED)" | Add-Content $ReportFile
"="*80 | Add-Content $ReportFile

# Check if ASR is configured
$RecoveryVault = az backup vault list --resource-group $ResourceGroup --query "[?properties.provisioningState=='Succeeded']" -o json 2>$null | ConvertFrom-Json

if ($RecoveryVault) {
 $VaultName = $RecoveryVault[0].name
 
 "`nRecovery Services Vault: $VaultName" | Add-Content $ReportFile
 
 # Get replication status
 $ReplicationItems = az backup item list --vault-name $VaultName --resource-group $ResourceGroup -o json | ConvertFrom-Json
 
 "`nProtected Items:" | Add-Content $ReportFile
 $ReplicationItems | ForEach-Object {
 " - $($_.properties.friendlyName): $($_.properties.protectionState)" | Add-Content $ReportFile
 }
} else {
 "Azure Site Recovery: Not Configured" | Add-Content $ReportFile
 "Note: ASR provides disaster recovery to Azure for critical VMs" | Add-Content $ReportFile
}
```

## Troubleshooting

| Issue | Cause | Resolution |
|-------|-------|------------|
| Backup job fails with VSS writer error | VSS writer in failed state on the node | Reset VSS writers: `vssadmin list writers`; restart the failing writer's service; retry backup |
| Restore test fails with timeout | Large backup or slow network to Recovery Services vault | Increase restore timeout; verify network bandwidth to Azure; consider restoring to a closer region |
| ASR replication shows `Critical` health | Replication agent offline or process server overloaded | Check process server health in Site Recovery; restart mobility service on affected VMs: `Restart-Service InMage Scout VX Agent - Sentinel/Outpost` |
