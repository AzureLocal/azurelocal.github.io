# Task 01: Enable Azure Hybrid Benefit

> **DOCUMENT CATEGORY**: Runbook
> **SCOPE**: Enable Azure Hybrid Benefit on Azure Local cluster to reduce Windows VM compu...
> **PURPOSE**: Enable Azure Hybrid Benefit on Azure Local cluster to reduce Windows VM compute costs
> **MASTER REFERENCE**: [Azure Hybrid Benefit for Azure Local](https://learn.microsoft.com/en-us/azure/azure-local/concepts/azure-hybrid-benefit)

**Status**: Active

:::danger[⚠️ LICENSING REQUIREMENT - NOT A DEFAULT ENTITLEMENT]

**Azure Hybrid Benefit is NOT included by default.** This benefit requires the customer to have:

1. **Windows Server Datacenter licenses** with **active Software Assurance (SA)**, obtained through:
 - Enterprise Agreement (EA) with active Software Assurance
 - Cloud Solution Provider (CSP) subscription
 - Microsoft Customer Agreement (MCA) with qualifying subscription

2. **Sufficient core licenses** - Each Windows Server core license entitles use on **one physical core** of Azure Local. You must allocate enough core licenses to cover **all physical cores** on all servers in the Azure Local cluster.

3. **Ongoing compliance** - Workloads using Azure Hybrid Benefit can run **only during the Software Assurance or subscription license term**. When the term approaches expiration, you must:
 - Renew your agreement with Software Assurance or subscription license, OR
 - Disable the Azure Hybrid Benefit functionality, OR
 - Deprovision workloads using Azure Hybrid Benefit

**⚠️ Microsoft reserves the right to audit customers at any time to verify eligibility for Azure Hybrid Benefit utilization.**

> **Reference**: [Azure Hybrid Benefit for Windows Server](https://learn.microsoft.com/en-us/windows-server/get-started/azure-hybrid-benefit) | [Azure Hybrid Benefit for Azure Local](https://learn.microsoft.com/en-us/azure/azure-local/concepts/azure-hybrid-benefit)

:::

Azure Hybrid Benefit allows you to use existing Windows Server licenses with Software Assurance to reduce costs for Windows VMs running on Azure Local.

:::note Scope of the benefit (verified October 2026)
Azure Hybrid Benefit for Azure Local waives the Azure Local host service fee and the Windows Server guest subscription fee. It applies only to hyperconverged deployments with cloud-connected management and no external storage. Disaggregated deployments, hyperconverged deployments with external storage, and disconnected operations are not eligible for the Azure Local benefit. You can't deactivate the benefit after activation. Source: [Azure Hybrid Benefit for Azure Local](https://learn.microsoft.com/en-us/azure/azure-local/concepts/azure-hybrid-benefit?view=azloc-2609).
:::

## Overview

Azure Hybrid Benefit provides:
- Up to 40% savings on Windows VM compute costs
- License mobility from on-premises to Azure Local
- Compliance with Microsoft licensing requirements

## Prerequisites

- [ ] Windows Server licenses with active Software Assurance
- [ ] Azure Local cluster registered with Azure Arc
- [ ] Owner or Contributor role on the cluster resource

## Execution Options

<Tabs groupId="deployment-method">
<TabItem value="manual" label="Azure Portal" default>

### Steps

1. Navigate to the **Azure portal** → **Azure Arc** → **Azure Local**
2. Select your cluster resource
3. Go to **Settings** → **Configuration**
4. Locate **Azure Hybrid Benefit** section
5. Toggle **Enable Azure Hybrid Benefit** to **On**
6. Review the licensing attestation
7. Click **Save**

### Verification

1. Return to the cluster **Overview** page
2. Confirm **Azure Hybrid Benefit** shows as **Enabled**

</TabItem>

<TabItem value="orchestrated" label="Orchestrated Script">

### PowerShell

> **When to use**: Run the task from a management workstation or a pipeline. The script reads `infrastructure.yml` and carries no values of its own.

| `scripts/deploy/05-operational-foundations/phase-05-licensing-telemetry/task-01-enable-azure-hybrid-benefit/powershell/Enable-AzureHybridBenefit.ps1` | Activates Azure Hybrid Benefit for the Azure Local instance when operations.licensing.azure_hybrid_benefit of infrastructure.yml is true. Supports `-WhatIf`. |

Requires: PowerShell 7.

./Enable-AzureHybridBenefit.ps1 -InfrastructureFile ./infrastructure.yml -WhatIf

## Verification

After enabling Azure Hybrid Benefit, verify the configuration:

```powershell
# On the cluster node
Get-AzStackHCI | Select-Object ClusterName, AzureHybridBenefit

# From management server
$cluster = Get-AzResource -ResourceId $ClusterResourceId
$cluster.Properties.softwareAssuranceProperties
```

## Troubleshooting

| Issue | Resolution |
|-------|------------|
| "Cluster not connected" | Verify Arc connection with `Get-AzStackHCI` |
| Permission denied | Ensure Owner or Contributor role on cluster resource |
| License attestation required | Review and accept the licensing terms in Azure Portal |
