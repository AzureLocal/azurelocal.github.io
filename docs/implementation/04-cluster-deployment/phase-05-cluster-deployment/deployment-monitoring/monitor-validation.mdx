## Overview

Validation checks the nodes, the network, the identity and the storage before the real deployment. It takes about 10 to 30 minutes. Watch it with [Azure Local Sonar](https://azurelocal.cloud/azurelocal-sonar/) instead of waiting on the portal.

## Steps

1. Start Sonar before you submit the validation:

   ```powershell
   Connect-AzAccount
   ./Start-AzlSonar.ps1 -InfrastructureFile ./infrastructure.yml
   ```

   Sonar reads the cluster, the nodes and the Azure targets from the master `infrastructure.yml` (schema 5), the same file the toolkit uses. It only reads: it changes nothing on the nodes or in Azure. Run it from any machine that can reach the nodes and has an Azure sign-in.

2. Start the validation, from the portal (**Start validation**) or from the toolkit:

   ```powershell
   ./Invoke-AzureLocalClusterDeployment.ps1 -InfrastructureFile ./infrastructure.yml -HandoffFile ./ztp-handoff.json -NodeReportPath ./osconfig-report.json -Mode Validate -Execute
   ```

3. Read the validation steps in Sonar. Fix every failed step, then validate again.

:::warning One failed Validate at a time
Do not start a second Validate while the instance is in a failed deployment state. Microsoft says a second Validate resets the system properties and can break license sync. `Invoke-AzureLocalClusterDeployment.ps1` refuses it for you.
:::

Sonar also shows the checks of the toolkit's pre-cluster verification and the known failures of the Validate step. See the [Sonar documentation](https://azurelocal.cloud/azurelocal-sonar/) for the page that matches your run.
