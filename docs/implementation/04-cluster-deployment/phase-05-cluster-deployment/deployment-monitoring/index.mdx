## Overview

Phase 05 cluster deployment runs in two steps: validation (about 10 to 30 minutes), then deployment (about 2.5 to 3 hours). Both run in the background from Azure's point of view, and the portal updates only now and then.

The toolkit has no monitoring scripts of its own for this any more. **Deployment progress is watched with [Azure Local Sonar](https://azurelocal.cloud/azurelocal-sonar/).** Sonar follows the validation steps, the deployment steps and the known failures live, and it is read only.

## Start Sonar

```powershell
Connect-AzAccount
./Start-AzlSonar.ps1 -InfrastructureFile ./infrastructure.yml
```

Sonar reads the cluster, the nodes and the Azure targets from the master `infrastructure.yml` (schema 5), the same file the toolkit uses. It only reads: it changes nothing on the nodes or in Azure. Run it from any machine that can reach the nodes and has an Azure sign-in.

Start it before you click **Start validation** or **Create** in the portal, or before you run `Invoke-AzureLocalClusterDeployment.ps1 -Execute`. Leave it open until the deployment ends.
