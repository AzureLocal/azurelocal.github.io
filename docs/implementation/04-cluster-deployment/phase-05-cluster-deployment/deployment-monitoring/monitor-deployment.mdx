## Overview

The deployment takes about 2.5 to 3 hours. Watch it with [Azure Local Sonar](https://azurelocal.cloud/azurelocal-sonar/). Sonar shows the deployment steps as they run, so you do not have to refresh the portal.

## Steps

1. Start Sonar before you create the deployment:

   ```powershell
   Connect-AzAccount
   ./Start-AzlSonar.ps1 -InfrastructureFile ./infrastructure.yml
   ```

   Sonar reads the cluster, the nodes and the Azure targets from the master `infrastructure.yml` (schema 5), the same file the toolkit uses. It only reads: it changes nothing on the nodes or in Azure. Run it from any machine that can reach the nodes and has an Azure sign-in.

2. Start the deployment, from the portal (**Create**) or from the toolkit:

   ```powershell
   ./Invoke-AzureLocalClusterDeployment.ps1 -InfrastructureFile ./infrastructure.yml -HandoffFile ./ztp-handoff.json -NodeReportPath ./osconfig-report.json -Mode Deploy -Execute
   ```

3. Leave Sonar open until the deployment ends. If a step fails, read the step and the known failures that Sonar shows before you act.
