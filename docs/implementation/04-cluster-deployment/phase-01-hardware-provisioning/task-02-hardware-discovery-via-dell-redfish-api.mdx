**Status**: Active

## Overview

Discover all cluster node hardware by connecting to each node's iDRAC via the Redfish API from the management server. This task collects everything needed for Tasks 03–05 in a single execution: hardware inventory, complete BIOS configuration, and complete iDRAC configuration.

**Data collected per node:**
- Service tag, model, BIOS version, firmware versions
- iDRAC MAC address
- System NIC MAC addresses
- All BIOS attributes (~256 settings) — used in Tasks 04 and 05
- All iDRAC attributes (~1024 settings) — used in Tasks 04 and 05
- CPU, memory, storage inventory

:::note No Node Access Required
All scripts in this task run **from the management server** and connect to iDRAC over the network via HTTPS (port 443). No access to the nodes themselves is required.
:::

## Values from infrastructure.yml

The script reads these keys from `infrastructure.yml` (schema 5). Each key, with its type, default and example, is in the [variables reference](https://github.com/AzureLocal/azurelocal-toolkit/blob/main/config/variables/docs/VARIABLES.md).

```text
nodes[]: name, bmc.ip_address, bmc.type, bmc.username, bmc.password, serial_number
hardware.bmc: username, password, verify_certificate
hardware.inventory: output_directory, file_name_prefix, format, timeout_seconds
hardware.vendor, hardware.model, hardware.cpu_cores, hardware.memory_gib, hardware.gpu (enabled, model, count_per_node),
hardware.drives (capacity and cache: media, count, size_tb): compared with what the BMC reports
secrets, key_vaults: read by the secret resolver for the references above
```

## Execution Options

<Tabs groupId="deployment-method">
<TabItem value="manual" label="Dell iDRAC UI" default>

> **When to use**: Single nodes, ad-hoc verification, or when scripted access is unavailable

### Procedure

1. Navigate to `https://<idrac-ip>` and log in with iDRAC credentials
2. **System Information**: Dashboard → record Service Tag, Model, BIOS Version
3. **iDRAC MAC**: iDRAC Settings → Network → record MAC Address
4. **System NICs**: System → Network Devices → record MAC addresses for all ports
5. **Export config**: Configuration → Export Server Configuration Profile → JSON format
6. Repeat for each node

### Validation

- [ ] Service tag recorded for all nodes
- [ ] iDRAC MAC addresses recorded for all nodes
- [ ] System NIC MAC addresses recorded for all nodes
- [ ] Configuration profiles exported and stored

### Update infrastructure.yml

After collecting data from all nodes, manually update the following fields in `infrastructure.yml`:

| Field | Source | Where to find it |
|-------|--------|-----------------|
| `nodes[].serial_number` | Service Tag | Dashboard → System Information |
| `nodes[].network_adapters[].mac_address` | The MAC address of each port (the management port first) | System → Network Devices → MAC for each port |
| `nodes[].network_adapters[].name` | NIC adapter name | System → Network Devices → adapter name (e.g., `Slot 3 Port 1` or `Embedded NIC 1`) |

:::warning Save and commit infrastructure.yml after updating
All subsequent tasks depend on these values. Do not proceed to Task 03 until `infrastructure.yml` is updated and committed.
:::

### PowerShell

> **When to use**: Run the task from a management workstation or a pipeline. The script reads `infrastructure.yml` and carries no values of its own.

#### Script

| Script | What it does |
|---|---|
| `scripts/deploy/04-cluster-deployment/phase-01-hardware-provisioning/task-02-hardware-discovery-via-dell-redfish-api/powershell/Get-HardwareInventory.ps1` | Reads the hardware of every node from its baseboard management controller (BMC) over the standard Redfish API and writes one inventory file. Supports `-WhatIf`. |
| `scripts/deploy/04-cluster-deployment/phase-01-hardware-provisioning/task-02-hardware-discovery-via-dell-redfish-api/powershell/Invoke-HardwareDiscovery.ps1` | Phase 01, Task 02: hardware discovery of every node through the Redfish API of its BMC (read only). This version: Dell iDRAC. |
| `scripts/deploy/04-cluster-deployment/phase-01-hardware-provisioning/task-02-hardware-discovery-via-dell-redfish-api/powershell/Update-InfrastructureYml-FromDiscovery.ps1` | Writes the serial numbers and port MACs found by hardware discovery into infrastructure.yml. Supports `-WhatIf`. |

Requires: PowerShell 7.

#### Run

```powershell
./Get-HardwareInventory.ps1 -InfrastructureFile ./infrastructure.yml -WhatIf

.\Invoke-HardwareDiscovery.ps1 -ConfigPath .\infrastructure.yml

.\Update-InfrastructureYml-FromDiscovery.ps1 -ConfigPath .\infrastructure.yml
```

## Troubleshooting

| Issue | Cause | Resolution |
|-------|-------|------------|
| `Connection refused` | iDRAC not accessible | Verify iDRAC IP and port 443 reachable from management server |
| `Authentication failed` | Incorrect credentials | Verify iDRAC password; check `root` account is enabled |
| `Certificate error` | Self-signed cert | Ensure PowerShell 7+ and `-SkipCertificateCheck` is used |
| `Timeout` | Slow iDRAC response | Check iDRAC is responsive via web UI; increase script timeout |
