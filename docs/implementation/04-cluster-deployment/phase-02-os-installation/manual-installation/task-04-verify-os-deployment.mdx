## Overview

Verify that Azure Stack HCI OS was installed correctly on every cluster node before moving to Phase 03: OS Configuration. Checks cover OS version, build number, boot drive assignment, network driver provider, and SConfig accessibility.

:::info Expected OS build for Azure Local 2610
Microsoft Learn 2610 lists solution version 12.2610.1004.50 with OS build **26100.33650**, and states that all new and existing deployments run that OS version (download it from the Azure portal). Drivers must be compatible with OS 26100.33650 (Windows Server 2025). `Get-ComputerInfo` returns only the major build (`26100`), so the checks below also read the update build revision (UBR) to get the full `26100.xxxxx` build. Media from an earlier release (for example 2604 to 2609) shows a lower revision and should be replaced with 2610 media. Integrated System or Premier solution hardware ships with the OS preinstalled: work with the OEM for a compatible OS image and driver.
:::

:::info Prerequisites Recap
- **Task 01**: BOSS virtual disk deleted and recreated ✓
- **Task 02**: Dell gold image ISO mounted / USB inserted ✓
- **Task 03**: Azure Stack HCI OS installed (Windows Setup completed) ✓

This task confirms Task 03 produced a healthy installation on every node.
:::

## Verification Options

<Tabs groupId="deployment-method">
<TabItem value="direct" label="Direct Script (On Node)">

Connect to each node via iDRAC Virtual Console and run the following commands directly at the Server Core prompt. Repeat for every node.

### Step 1 — Open iDRAC Virtual Console

1. Open `https://<idrac-ip>` for the target node
2. Navigate to **Dashboard** → **Virtual Console** → **Launch**
3. Log in as `Administrator` with the password set during Task 03

### Step 2 — Verify OS Version and Build

```powershell
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion, OsBuildNumber
(Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion').UBR
```

**Expected Output** (Azure Local 2610):
```
WindowsProductName : Azure Stack HCI
WindowsVersion : 24H2
OsBuildNumber : 26100
33650
```

The full build is `26100.<UBR>`; for 2610 media it is `26100.33650`. A lower revision means older media.

### Step 3 — Verify Boot Drive (BOSS Card)

```powershell
# Confirm OS is on the BOSS drive (~238 GB)
Get-Disk | Format-Table Number, FriendlyName, Size, OperationalStatus
Get-Volume -DriveLetter C | Format-Table DriveLetter, FileSystemLabel, Size, SizeRemaining
```

**Expected:** C: drive size approximately 238 GB (BOSS RAID-1 volume).

### Step 4 — Verify Network Adapters are Visible

```powershell
Get-NetAdapter | Format-Table Name, InterfaceDescription, Status
```

All physical NICs should be listed. IP addresses are not expected at this stage — networking is configured in Phase 03.

Also check which driver each adapter uses. Inbox drivers are not supported for Azure Local (Microsoft Learn): an adapter is using an inbox driver if `DriverProvider` is `Microsoft`.

```powershell
Get-NetAdapter -Physical | Select-Object Name, InterfaceDescription, DriverProvider, DriverVersion, DriverDate
```

**Expected:** `DriverProvider` is the NIC vendor or OEM (for example Intel, Mellanox/NVIDIA, Broadcom), not `Microsoft`. If it is `Microsoft`, install the latest OEM driver following the OEM's instructions before continuing.

### Step 5 — Verify SConfig

Type `sconfig` at the prompt and confirm the SConfig menu loads without errors. Press `15` to exit back to the command prompt.

### Repeat

Perform Steps 1–5 for each remaining node before proceeding.

## Troubleshooting

| Issue | Cause | Resolution |
|-------|-------|------------|
| Wrong OS version / product name | Incorrect ISO used in Task 02 | Reinstall with the correct Dell gold image |
| Build number below 26100.33650 | Media from an earlier release | Obtain the 2610 OS image (Azure portal download or OEM image) and reinstall |
| `DriverProvider` is `Microsoft` | Inbox NIC driver in use (not supported) | Install the latest OEM driver per the OEM's instructions |
| Can't connect remotely (WinRM) | WinRM not yet configured | Use Direct Script tab; enable WinRM manually: `winrm quickconfig -q` |
| Cannot connect via iDRAC console | iDRAC network issue | Verify iDRAC IP and OOB connectivity |
| Boot drive wrong size | OS installed on data drive, not BOSS | Reinstall — return to [Task 03](./task-03-manual-os-installation.mdx) and select Drive 0 |
| Node not booting | Boot order or BOSS issue | Verify BIOS boot order; return to [Task 01](./task-01-delete-and-recreate-virtual-disk-on-dell-boss-card.mdx) |
| SConfig not accessible | Installation incomplete | Verify installation completed; reboot node |
