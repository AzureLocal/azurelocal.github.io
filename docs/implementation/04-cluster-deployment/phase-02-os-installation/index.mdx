## Overview

Phase 02 has two paths. Both end with the Azure Stack HCI OS on every node, but they hand over in different states, so the phases after them differ too.

| Path | What it is | Next |
|------|-----------|------|
| **[Manual OS Installation (ISO)](./manual-installation/index.mdx)** | You install from the ISO or your OEM's image on each node through the BMC console. GA. | All of [Phase 03](../phase-03-os-configuration/index.mdx), then [Phase 04](../phase-04-arc-registration/index.mdx) |
| **[Simplified Machine Provisioning](./simplified-provisioning/index.mdx)** | Azure installs the OS, sets the host name and registers the machine with Arc. Preview. By hand in the portal, or fully automated with azurelocal-ztp. | Simplified provisioning Task 06, or the ZTP Prepare stage. Phase 04 is skipped |

[Choose your route](../choose-your-route.mdx) has the flow chart for the whole of Part 4 and a decision matrix of every OS step on each path.

:::tip Zero-touch provisioning: azurelocal-ztp
**Simplified provisioning can run with no one in the rack.** The [azurelocal-ztp](https://azurelocal.cloud/azurelocal-ztp/) automation boots each machine from a virtual USB over the BMC, collects the ownership vouchers, claims the machines in Azure, installs the OEM network drivers and SBE, and checks every machine until it's ready for Validate. One command from a Windows management host, or one pipeline.

- Documentation: [azurelocal.cloud/azurelocal-ztp](https://azurelocal.cloud/azurelocal-ztp/)
- Source: [github.com/AzureLocal/azurelocal-ztp](https://github.com/AzureLocal/azurelocal-ztp)
- On this site: [Automated route](./simplified-provisioning/automation/index.mdx)

Proven on Dell AX-760 with iDRAC 7.30. Not Microsoft-supported.
:::

## Path comparison

| Aspect | Manual (ISO) | Simplified provisioning (preview) |
|--------|-------------|-----------------------------------|
| **Status** | ✅ GA, production supported | ⚠️ Preview, East US only |
| **OS installation** | By hand through the iDRAC or BMC console | By Azure |
| **Physical access** | iDRAC virtual media | A USB stick per machine, or none with azurelocal-ztp |
| **Host name** | You set it in Phase 03 | Set by provisioning |
| **OEM drivers and SBE** | In the OEM image, or you install them | You install them (Task 06), or azurelocal-ztp does |
| **Network configuration** | Phase 03 | DHCP from provisioning; static IP, one gateway, DNS and time in Task 06 or by azurelocal-ztp |
| **Azure Arc registration** | Phase 04 | Done by provisioning |
| **Arc machine name** | The host name | `<device-id>-1`, see the [known issue](../choose-your-route.mdx#known-issue-arc-machine-names-at-deploy) |
| **Arc gateway** | ✅ Supported | ❌ Not supported in the preview |
| **Validated hardware** | All [Azure Local catalog](https://aka.ms/AzureStackHCICatalog) hardware | Dell AX-650/750, Lenovo MX650 V3/V4, HPE DL360 Gen11 |

:::tip Recommendation
Use the **manual (ISO)** path for production deployments until simplified provisioning reaches GA. Use simplified provisioning for evaluation, and on its validated hardware in East US.
:::

## Outcome

- **Manual path:** the OS is on every node. Continue with [Phase 03](../phase-03-os-configuration/index.mdx).
- **Simplified path:** every machine is Ready to cluster in Azure, with OEM drivers, SBE, one static management address, DNS and time. Phase 04 is skipped; continue with [Phase 05](../phase-05-cluster-deployment/index.mdx).

:::warning Before Validate, on either path
Check [Microsoft Learn's OS installation steps](https://learn.microsoft.com/en-us/azure/azure-local/deploy/deployment-install-os?view=azloc-2610) and your OEM's deployment guide for your build and hardware.
:::
