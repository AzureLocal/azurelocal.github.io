## Overview

If nodes have previously been used with Storage Spaces Direct, all existing storage pools, virtual disks, and disk metadata must be cleared before Azure Local deployment.

:::danger Data Loss Warning
This step **DESTROYS ALL DATA** on the **local** data disks. Ensure all data is backed up before proceeding. This is irreversible.
:::

:::danger Never run a local-disk wipe against SAN LUNs
The scripts below skip every disk whose `BusType` is `Fibre Channel` or `iSCSI`, and they only reset physical disks that are not on those buses. This `BusType` filter is a safety guard added by this runbook, not a Microsoft step. SAN LUNs belong to the storage array, not to the node.

- **Disaggregated (SAN-only):** the infrastructure (250 GB or larger) and performance history (20 GB or larger) LUNs must stay **RAW** and are presented before deployment. Do not clear, initialize or reset them from this task. If a LUN holds an old configuration, clean it on the array side with your storage administrator.
- **Hybrid (S2D + SAN):** SAN LUNs are attached only after the initial deployment. If you redeploy a hybrid cluster, disconnect or unmask the SAN LUNs first so a wipe cannot reach them.

Microsoft Learn tells you to clean the non-OS drives on the machines you deploy: "Clean all the non-OS drives for each machine that you intend to deploy... This step doesn't apply to a machine repair operation" ([Install the OS](https://learn.microsoft.com/en-us/azure/azure-local/deploy/deployment-install-os?view=azloc-2610)). For disaggregated deployments, Learn says "Don't initialize the drives, as the deployment expects the drive type to be RAW" ([Install the OS for disaggregated deployments](https://learn.microsoft.com/en-us/azure/azure-local/deploy/deployment-install-os-disaggregated?view=azloc-2610#connect-to-san)).
:::

## Execution Options

<Tabs groupId="deployment-method">
<TabItem value="direct" label="Direct (On Node)" default>

Run on each node individually via console, KVM, or RDP.

**Toolkit script:** `scripts/deploy/04-cluster-deployment/phase-03-os-configuration/task-11-clear-previous-storage-configuration-conditional/powershell/Clear-StorageConfiguration-Direct.ps1`

```powershell
# Task 11 - Clear Previous Storage Configuration (run locally on target node)

Update-StorageProviderCache
Get-StoragePool | ? IsPrimordial -eq $false | Set-StoragePool -IsReadOnly:$false -ErrorAction SilentlyContinue
Get-StoragePool | ? IsPrimordial -eq $false | Get-VirtualDisk | Remove-VirtualDisk -Confirm:$false -ErrorAction SilentlyContinue
Get-StoragePool | ? IsPrimordial -eq $false | Remove-StoragePool -Confirm:$false -ErrorAction SilentlyContinue
Get-PhysicalDisk | ? BusType -notin 'Fibre Channel','iSCSI' | Reset-PhysicalDisk -ErrorAction SilentlyContinue
Get-Disk | ? Number -ne $null | ? IsBoot -ne $true | ? IsSystem -ne $true | ? PartitionStyle -ne RAW | ? BusType -notin 'USB','Fibre Channel','iSCSI' | % {
 $_ | Set-Disk -isoffline:$false
 $_ | Set-Disk -isreadonly:$false
 $_ | Clear-Disk -RemoveData -RemoveOEM -Confirm:$false
 $_ | Set-Disk -isreadonly:$true
 $_ | Set-Disk -isoffline:$true
}
Get-Disk | Where Number -Ne $Null | Where IsBoot -Ne $True | Where IsSystem -Ne $True | Where PartitionStyle -Eq RAW | Group -NoElement -Property FriendlyName
```

## Validation

```powershell
# Verify all data disks are CanPool = True
$ServerList = @("<node1-ip>", "<node2-ip>")
Invoke-Command ($ServerList) {
 Get-PhysicalDisk | Where-Object { $_.BusType -notin 'USB','Fibre Channel','iSCSI' } |
 Select-Object FriendlyName, CanPool, CannotPoolReason, BusType, MediaType
} | Format-Table -AutoSize
```

**Expected:** All local data disks show `CanPool = True`. SAN LUNs (`Fibre Channel` or `iSCSI`) are not listed and must not be touched. Boot disk shows `CannotPoolReason = Insufficient Capacity` — this is expected.

## Troubleshooting

| Issue | Resolution |
|---|---|
| `CanPool = False` after running | Re-run `Reset-PhysicalDisk` |
| Storage pool still exists | Remove from cluster first, then re-run |
| A SAN LUN is no longer RAW | Do not reuse it as the infrastructure or performance history LUN. Ask the storage administrator to recreate or wipe it on the array, then present it again (see [Task 14](./task-14-verify-san-lun-presentation-conditional.mdx)) |
