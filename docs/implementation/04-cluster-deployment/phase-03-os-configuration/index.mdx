## Start here: the automated run

OS configuration always starts **after** the OS install, whichever way it was done. The toolkit does the whole phase for the whole cluster in one run: it reads each node, changes only what differs from the master `infrastructure.yml`, and reports. Use it unless you cannot; the manual tasks below do the same work one setting at a time.

![Decision flow from the OS install method to OS configuration and on to ARM Validate and ARM Deploy.](/img/os-configuration/provisioning-to-os-configuration.png)

:::info Installed with simplified machine provisioning?
Provisioning sets the host name, registers the machine with Arc and installs the mandatory extensions. [azurelocal-ztp](../phase-02-os-installation/simplified-provisioning/automation/index.mdx) ends at the Handoff: it does **not** install the OEM drivers or the SBE, set DNS or time, create the deployment administrator, or turn DHCP and the default gateway off on the other ports, and in management Modes B and C the static address is not in place. The automated run does all of that, starting from the handoff. See the [decision matrix](../choose-your-route.mdx#decision-matrix) for each task, and check [Microsoft Learn](https://learn.microsoft.com/en-us/azure/azure-local/deploy/deployment-install-os?view=azloc-2610) and your OEM's deployment guide for your build before Validate.
:::

## Manual tasks

This stage configures the Azure Stack HCI operating system on all cluster nodes with the settings required for Azure Local deployment. All steps can be performed remotely once WinRM is enabled.

**Objective:** Configure the Azure Local operating system on each node with network settings, remote management, and baseline configuration required for cluster deployment.

**Tasks:**

1. Enable WinRM for PowerShell remote management
2. Enable RDP for graphical remote access
3. Configure static IP addresses on management adapters
4. Disable DHCP on management adapters
5. Configure DNS server addresses
6. Verify DNS client configuration
7. Configure NTP time synchronization
8. Enable ICMP firewall rules for network diagnostics
9. Disable unused network adapters
10. Set node hostnames
11. Clear previous storage configuration (conditional — redeployments on used hardware; local disks only, never SAN LUNs)
12. Install FC HBA drivers or OEM iSCSI adapter drivers (conditional — disaggregated SAN deployments)
13. Verify MPIO, register and claim the vendor MSDSM (conditional — disaggregated SAN deployments)
14. Verify SAN LUN presentation (conditional — disaggregated SAN deployments)
15. Optional: Run complete combined script (Tasks 02–10)
16. Phase 03 Verification

**Validation:**

- Remote management operational (WinRM and RDP)
- Static network configuration applied
- DNS resolution functional
- Time synchronization configured
- Nodes accessible and properly named

**Outcome:** All nodes configured with proper network settings, remote management enabled, and ready for Azure Arc registration (Stage 13).

## Variables from infrastructure.yaml

The following variables are used during OS configuration:

| Variable | Description | Example |
|----------|-------------|---------|
| `NODE_XX_IP` | Static IP address for each node | `192.168.200.11` |
| `NODE_XX_NAME` | Hostname for each node | `azlocal-node01` |

| `MANAGEMENT_SUBNET_PREFIX` | Subnet prefix length | `24` |
| `DNS_PRIMARY_IP` | Primary DNS server IP | `192.168.200.2` |
| `DNS_SECONDARY_IP` | Secondary DNS server IP | `192.168.200.3` |

## Automation Options

**Manual**: Follow each step in sequence.

**Automated, the whole phase**: the [automated run](./automated-os-configuration.mdx) covers every task on this page for every node, with method detection, a plan, an approval gate and a verification pass.

**Automated, Tasks 02–10 only**: [Task 15: Combined Script](./task-15-complete-combined-script-all-steps.mdx).

**Disaggregated SAN deployments**: Run Tasks 12–14 after Task 11 before running the combined script. Zone the FC fabric and unmask the infrastructure and performance history LUNs now, before Arc registration, and leave them RAW. On iSCSI with 2610, do not enable iSCSI on the machines first; the deployment wizard configures it.

**Hybrid (Storage Spaces Direct + SAN)**: Skip Tasks 12–14 for the initial deployment. Learn attaches the SAN after the initial deployment (2604 or later) and says: "don't zone in FC HBA World Wide Names (WWNs) until after the Azure Local deployment." Follow [Connect an external storage array to Azure Local](https://learn.microsoft.com/en-us/azure/azure-local/deploy/enable-external-storage?view=azloc-2610) once the cluster is deployed.
