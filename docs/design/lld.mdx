# Low-Level Design (LLD)

:::info Placeholder
This document is under development. The Low-Level Design will provide detailed technical specifications for each component of the Azure Local deployment.
:::

## Scope

The LLD will include:

- **Network Design** — VLAN assignments, IP addressing, subnet allocation, firewall rules, Network ATC intent pattern (2, 4, 6 or 8 ports per node: management, compute, storage), RDMA and jumbo frames on the storage intent, and DNS (fixed after deployment)
- **Storage Architecture** — Storage Spaces Direct configuration, volume layout, and performance tiers; SAN LUN layout, MPIO and zoning where a SAN is used
- **Compute Design** — Node specifications, cluster configuration, and resource allocation
- **Identity Configuration** — OU structure, service accounts, GPO assignments (Active Directory), or Key Vault and DNS zone settings (local identity)
- **Security Baselines** — Hardening standards, encryption settings, and compliance requirements
