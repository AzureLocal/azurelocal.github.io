This section documents the automation. The [Implementation Guide](../../implementation/04-cluster-deployment/phase-03-os-configuration/index.mdx) keeps the manual, step-by-step tasks and links to the same PowerShell scripts in the [azurelocal-toolkit](https://github.com/AzureLocal/azurelocal-toolkit). The two guides describe the same work, so a change to one needs a matching change to the other.

## Pages in this section

| Page | What it gives you |
|------|-------------------|
| [Which method did I use?](./which-method-then-os-configuration.mdx) | The decision flow from the OS install (azurelocal-ztp or a manual ISO install) to ARM Deploy, method detection, and how to tell which method you used |
| [Automated OS configuration (one run)](./automated-os-configuration.mdx) | The commands (standalone and from a GitHub or GitLab pipeline), the master-file keys, `clear_storage`, the SBE delivery route, exit codes, access and connectivity, and troubleshooting |
| [How the run works](./how-the-run-works.mdx) | Every step in the order it runs, what counts as a change, restarts, the three management address modes, SAN-only steps |
