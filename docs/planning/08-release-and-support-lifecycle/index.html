Releases and Support Lifecycle

DOCUMENT CATEGORY: Reference SCOPE: Azure Local release model, supported builds, and feature changes PURPOSE: Plan which release to deploy, how long it stays supported, and what changed recently MASTER REFERENCE: Microsoft Learn — Azure Local release information

Status: Active

Current release​

The latest release of Azure Local is 12.2609 (September 2026). New deployments use build 12.2609.1003.7, available since 11 September 2026, with OS build 26100.33438.

Build numbers

Solution versions are written 12.<YYMM>.<build>. This site says "2609" or "12.2609" for the release train. Microsoft publishes the exact build number and OS build for each train on the release information page.

Release model​

Azure Local moved from one annual release to a monthly release train. Each train is one of the following:

Build typeWhat it contains
Feature buildThe first build in a train. Adds product enhancements, including updates to Azure Local services and agents.
Cumulative buildIncremental updates on top of the most recent feature build.
Quality buildOptional, security-only, not cumulative. Starting with 2604, quality updates are available before the cumulative update.

Key points that affect planning:

  • Starting with 2504, there are two solution versions each month. Version 11.25xx stays on OS build 25398 (23H2). Version 12.25xx or 12.26xx runs OS build 26100 (24H2). Each version keeps its OS build for all later updates.
  • Before you install a feature update, install the last cumulative update. For example, install 2509 before you install 2510.
  • Feature releases reach clusters that use a Solution Builder Extension (SBE) after your hardware vendor validates them. This typically takes a few weeks and varies by vendor. See Update management and Solution Builder Extension.
  • The Azure Arc resource bridge requires solution updates to be applied within one year, to keep certificates valid and Azure Local VM management working.

Supported builds​

Each Azure Local release is supported for six months. If you do not update within six months, the solution is no longer supported, and Microsoft Support can only help you update to a supported version.

Azure Stack HCI 23H2 is out of support

The Azure Stack HCI, version 23H2 operating system (OS build 25398) reached end of support in April 2026. October 2025 (11.2510) was the final 23H2 release. Systems still on 25398 receive no monthly security or quality updates, and support requests are limited to patching to a supported release. Move them to the 12.x train.

Naming​

Azure Stack HCI was renamed Azure Local. Some portal wizards, PowerShell cmdlet names (for example Invoke-AzStackHciArcInitialization), built-in role names (for example Azure Stack HCI Administrator), and OS strings still use the older name. Treat them as the same product.

Planning guidance​

  1. Target the latest train (12.2609) for new deployments. Hardware that ships with an older preinstalled OS can be updated after Azure Arc registration.
  2. Budget a recurring update window. A cluster that falls more than six months behind is unsupported.
  3. Confirm with your hardware vendor which Solution Builder Extension version matches the release you plan to run.
  4. Re-check known issues before each maintenance window.
