# Disconnected Operations

Disconnected operations let you deploy and manage Azure Local instances without a connection to the Azure public cloud. You run a local control plane that gives you a familiar Azure portal, Azure Resource Manager, and Azure CLI experience, with data, operations, and control inside your own boundary.
